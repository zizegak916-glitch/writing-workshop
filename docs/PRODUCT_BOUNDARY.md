# Writing Workshop 产品归属与运行边界

> 状态：现行产品规则。更新于 2026-08-21（UTC）。

这份文档回答三个问题：什么属于 Writing Workshop，什么只是可选服务，什么完全属于外部。

## 1. Writing Workshop 产品层

以下能力由本仓库的 Web 产品层提供，也是公开 Pages 的主体：

- 浏览器本地项目、章节、大纲、人物、笔记、记忆与自定义分类；
- 编辑器、自动保存、项目备份、导入、导出与迁移；
- 32 个可查看、修改、恢复和备份的浏览器 Prompt Skill；
- 显式上下文选择、token 估算、候选区、写入确认和写前快照；
- OpenAI Chat Completions、Responses、Anthropic Messages 与 Ollama 的浏览器 API 适配；
- 工作台、产品文档、隐私说明和项目内原生图标。

这些能力不属于某个论坛，也不要求用户进入第二套“社区后台”。

## 2. 可选本地服务

仓库同时包含基于已署名上游引擎维护的 Go 服务集成，用于服务端密钥托管、同源 API、后端项目、规则、后端 Skill、技能包、能力目录、SSE 和中断。上游原始作者归属不会因为 fork 或集成而转移；Writing Workshop 只对本仓库后续产品层和改动负责。

- 它由本仓库维护，但不是 Pages 在线版的必需依赖。
- `admin.html` 的准确名称是“本地服务控制台”，不是独立产品后台。
- 工作台只有检测到同源 Go 服务时才显示“服务”入口。
- 静态托管直接访问该页面时，只显示浏览器 API 配置和测试；服务端栏目必须隐藏。
- 浏览器项目和后端项目是两套存储，只有用户显式导入时才建立副本。

## 3. 外部平台、社区与上游

| 对象 | 与项目的关系 | 不代表什么 |
|---|---|---|
| GitHub / GitHub Pages | 代码与静态站托管平台 | 不是产品所有者或用户数据同步服务 |
| 模型供应商与中转接口 | 用户自行选择的 API 服务 | 不由本项目运营、担保或控制 CORS |
| `voocel/ainovel-cli` | Apache-2.0 上游 Go 引擎 | 不等于 Writing Workshop 的 Web 产品层 |
| LINUX DO 及其他论坛 | 外部讨论、反馈或发布社区 | 不是后台、官网、客服、账号系统或所有者 |
| 外部 Agent Skills / MCP 项目 | 可核验的能力参考来源 | 登记链接不等于安装、启用或执行代码 |

## 4. 界面与文档规则

1. 产品主导航只包含工作台、文档、关于、隐私、GitHub 和 Issues。
2. 外部社区只出现在明确标注的“外部社区与上游”致谢或历史发布材料中。
3. 不把论坛账号写成隐私、安全或产品客服联系方式。
4. 不把本地服务控制台放进 Pages 主导航，也不在未连接服务时展示不可用栏目。
5. 历史时间线保留当时事实，不通过改写历史来掩盖后来纠正的边界。

## 5. 变更检查

任何涉及导航、联系渠道、运行模式或上游署名的变更，都应同时检查：

- `web/static/index.html`、`app.html`、`about.html`、`privacy.html`、`docs.html`；
- `web/static/admin.html` 的静态/自部署分支；
- `README.md`、本文件和 `docs/UI_DESIGN_SYSTEM.md`；
- `scripts/check-static.mjs` 的产品边界断言。
