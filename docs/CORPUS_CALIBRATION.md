# 授权语料校准实验室

> 现行功能说明，更新于 2026-08-23（UTC）。

## 它解决什么问题

固定提示词很容易变成抽象写作建议。语料校准实验室允许作者导入自己有权分析的真实稿件或网文样本，用可解释的统计信号细化 Prompt Skill，同时避免保存原文、训练模型或仿写某个作者。

## 使用方法

1. 进入工作台“流程 → 授权语料校准”。
2. 选择 TXT、Markdown 或 DOCX；单文件最多 20 MiB，自部署一次最多 20 个文件。
3. 勾选“我有权分析这些文本”。没有确认时不会开始。
4. 查看文件哈希、样本量、证据等级和聚合指标。
5. 选择要校准的 Prompt Skill。
6. 生成候选差分。多份来源先按来源等权取中位基线，再分别为续写、节奏、对白/角色、润色/改写生成相关规则。
7. 若来源之间的对白密度或段落长度明显分歧，先检查候选中的“弱约束”，不要把它当成硬指标。
8. 如果效果不合适，点击撤销，恢复每个 Skill 应用前的提示词。

## 保存什么

| 数据 | 是否保存 | 用途 |
|---|---:|---|
| 原文 | 否 | 只在本次分析的内存中存在 |
| 文件名、格式、大小 | 是 | 用户识别来源 |
| SHA-256 | 是 | 去重和校验 |
| 章节/段落/句长/对话/标点等指标 | 是 | 形成可解释规则 |
| 频率摘要 | 是 | 发现机械重复，不保存完整段落 |
| Prompt Skill 候选与应用前快照 | 是 | 预览、应用和撤销 |

自部署档案位于 `.writing-workshop/corpus/index.json`。Pages 在浏览器本地完成分析，原文不上传；项目 v6 备份可携带统计档案和校准历史，但不含导入原文。

## 不能做什么

- 不得导入无权处理、违反平台条款或含不应处理隐私的数据。
- 不把来源作者名写成风格指令，不提供“模仿某作者”按钮。
- 不把来源作品的专名、情节、句子或连续表达写入新稿。
- 不自动覆盖全部 Prompt Skill；只生成候选，必须由作者确认。
- 统计相近不代表文学质量相同，弱样本不能被当成强结论。

## 指标与规则

当前引擎计算：字符数、章节数、段落数、句数、平均段/句长、段长变异、对话比例、短段比例、长句比例、解释性连接词比例、每千字标点、句首频率和有限采样的重复短语。单本档案标注 `weak`、`moderate` 或 `strong` 证据等级；多本联合校准采用 `equal-source-median-v2`，每个来源等权，防止字数最长的一本自动压过其他样本。

联合校准不会把所有单本规则直接并集。它先形成统计共识，检测分歧，再按目标 Skill 选择相关维度。统计锚点不是字数配额，也不能越过人物逻辑、项目设定和用户当次指令。

它不会把整部作品交给模型重新总结。新增文件只分析新增文件，SHA-256 相同则去重；成本随新增资料增长，而不是随全部历史资料反复增长。

## API

- `GET /api/corpus`：读取聚合档案。
- `POST /api/corpus`：multipart 上传授权文件，字段 `files` 和 `authorized=true`。
- `DELETE /api/corpus?id=...`：删除一个聚合档案。
- `POST /api/corpus/refinements`：基于 `source_ids` 和 `target_skills` 生成未应用候选。

服务端返回的 proposal 永远带 `applied:false`；实际 Prompt Skill 写入在浏览器确认后发生。
