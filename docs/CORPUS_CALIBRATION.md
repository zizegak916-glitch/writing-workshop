# 真实网文指导与校准

## 它解决什么问题

固定提示词容易停留在抽象建议，少量平均值又会把不同场景压成同一节奏。指导库允许作者导入自己有权分析的真实稿件或网文，先用浏览器或 Go 引擎完成可复核的本地分析，再选择是否让已配置模型深析分层抽样。结果既能调整 Prompt Skill，也能在实际写作时按任务动态指导。

它不是训练器或具体作者仿写器。来源作品的作者身份、专名、人物、情节、句子和连续表达都不能成为新稿素材。

## 两条使用链路

### 写作指导

1. 进入工作台“流程 → 真实网文指导库”。
2. 选择 TXT、Markdown 或 DOCX；单文件最多 20 MiB。
3. 确认拥有分析权限，运行“本地完整分析”。
4. 查看综合总结，以及每张指导卡的适用范围、证据和反例。
5. 保持档案启用。此后润色、续写、对白、节奏等请求会只调用与当前 Skill 相关的卡片。
6. 可以把综合总结或单张卡片写入项目记忆；自部署还可以显式写入 Go 后台记忆。

### 提示词调整

1. 勾选目标 Prompt Skill，生成候选。
2. 选择“追加到现有提示词”“修改现有指导块”或“整段替换提示词”。
3. 直接编辑完整预览，或让已配置模型修改候选。
4. 确认后才应用。每个 Skill 都保存应用前的完整提示词，可精确回退。

## 本地分析内容

本地引擎不只计算平均段长。当前包括：

- 常见中文数字、阿拉伯数字和英文 Chapter 标题识别；
- 段长与句长的平均数、中位数和 90 分位数；
- 位于段首或段中的中文/英文引号对白及对白轮次；
- 短段、长句、解释标记句和动作动词句比例；
- 章节收束信号、场景分隔、句首重复与有限采样的重复短语；
- 样本量、章节识别可靠性和来源间分歧提示。

指标会被整理成任务指导卡，而不是直接成为配额。每张卡必须说明什么时候适用、依据是什么、什么时候不应套用。

## 可选 AI 深析

AI 深析不是本地分析的替代品。它先接收本地指标，再读取最多约 18,000 字的分层抽样：开头、四分之一处、中段、四分之三处、结尾、对白较密段和若干章末。它应补充本地统计难以判断的场景推进、人物行动、对白功能、信息释放与章节收束方法，并把不确定项单列。

只有用户点击“AI 深度分析”才会发送这些抽样。刷新页面后原文与抽样从内存消失；已确认的分析总结和指导卡仍保存在档案中。

## 保存与发送

| 数据 | 默认保存 | 发送给模型 |
|---|---:|---:|
| 导入原文 | 否 | 否 |
| AI 深析分层抽样 | 否 | 仅主动点击时 |
| 文件名、格式、大小、SHA-256 | 是 | 只作为分析元数据 |
| 本地指标、总结、指导卡 | 是 | 写作请求按 Skill 选择后发送 |
| AI 深析总结与指导卡 | 是 | 写作请求按 Skill 选择后发送 |
| 提示词候选与应用前快照 | 是 | 只有执行 AI 修改候选时发送预览 |

自部署语料档案位于 `.writing-workshop/corpus/index.json`，后台记忆位于 `.writing-workshop/memories.json`。项目 v6 备份可携带分析档案和提示词历史，不含导入原文。

## 优先级与边界

指导库的优先级低于用户本次要求、项目正式事实、人物知识边界、当前文本已形成的声音和明确记忆。来源之间冲突时不强行合并成一条规则；统计结论不能证明文学质量，AI 推断也不能冒充事实。

## API

- `GET /api/corpus`：读取分析档案。
- `POST /api/corpus`：multipart 上传授权文件，字段为 `files` 和 `authorized=true`。
- `DELETE /api/corpus?id=...`：删除一个分析档案。
- `POST /api/corpus/refinements`：基于 `source_ids` 和 `target_skills` 生成未应用候选。
- `GET|POST|PUT|DELETE /api/memories`：管理 Go 后台记忆。

服务端 proposal 永远不会自动写入 Prompt Skill；实际提示词写入在浏览器确认后发生。
