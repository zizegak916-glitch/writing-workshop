# Prompt Skill 架构

> 现行实现说明，更新于 2026-08-23（UTC）。

浏览器 Prompt Skill 不是给 32 个按钮分别塞一段角色扮演文本。当前请求由三层组成：

1. 每个 Skill 独有的任务定义与输出契约；
2. 全 Skill 共用的信息优先级、事实保护和授权语料边界；
3. 修改、生成、分析、策划、研究五类不同的静默执行协议。

## 信息优先级

从高到低为：用户本次明确要求、项目正式设定与禁令、当前局部人物/世界/大纲/记忆、原文事实、授权语料聚合信号、通用写作经验。局部具体且较新的确认信息优先，不自动调和矛盾来源。

真实网文语料只校正句长、段落、对白密度、节奏与重复表达等聚合倾向。它不能提供情节事实、作者身份或硬比例，也不能覆盖人物逻辑和项目规则。

## 五类执行协议

| 类型 | 主要检查 |
|---|---|
| 修改 | 保护事实和信息点，只改真实问题，提取原文声音，逐项回查越界与模板化表达 |
| 生成 | 还原场景状态和人物知识，以触发—判断—选择—反应—新状态形成因果链 |
| 分析 | 先判断问题是否成立，区分错误、风险、取舍和偏好，证据与最小修法绑定 |
| 策划 | 分离事实、推断、待定与禁区，以人物选择、阻力、代价和后果组织候选 |
| 研究 | 区分史实、制度、词义年代与活语言；事实用权威来源，表达自然度用真实语料 |

默认完整提示词在 `web/static/js/prompt-skills.js` 中组装。用户覆盖值仍是完整 Prompt Skill，保存在 `ww_prompt_skills_v1`；恢复默认会回到当前仓库版本。真实网文指导库有两条明确链路：启用的指导卡会按当前 Skill 动态注入每次请求；提示词工作台则可追加、修改或整段替换可查看、可撤销的候选块。
