Open-source writing infrastructure

让 AI 参与创作，但不接管作品。

Writing Workshop 是面向小说与长篇内容的本地优先工作台：资料、上下文、能力和写入动作都由作者明确控制。

我们在解决什么

长篇项目的难点不是“再生成一段”，而是维护角色、设定、章节、记忆与修改边界，同时避免上下文成本随资料库无限增长。

产品原则

显式上下文、候选先行、作者确认、写前快照、本地默认、能力可审计。模型能力可以替换，作者控制不能消失。

浏览器能力

项目管理、资料分类、32 个可修改 Prompt Skill、显式上下文、候选写入保护和导入导出属于工作台本身，不依赖所谓“社区后台”。

开放协作

项目采用 Apache-2.0 许可证，包含 Go 同源后端、原生 Web 前端、协议文档、CI、Docker、Pages 与发布工作流。

归属与运行边界

Writing Workshop 是本仓库独立维护的写作产品。GitHub Pages 是公开托管方式；仓库随附的原生 Go 引擎与本地服务负责同源 API、密钥托管、后端 Skill 和授权语料聚合分析。模型厂商、GitHub 与任何论坛社区都不是本产品的一部分。完整边界见 产品归属说明。

外部社区与上游

感谢 LINUX DO 佬友曾提供交流与反馈环境；它是外部社区，不是 Writing Workshop 的后台、官网、客服或所有者。仓库最初 fork 自 Apache-2.0 许可的 voocel/ainovel-cli，许可证、署名和历史继续保留；当前 internal/engine 已不再导入早期的 agentcore/litellm 运行时依赖。
