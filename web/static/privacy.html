Privacy by architecture

作品默认留在你掌控的环境。

以下说明区分静态 Pages、浏览器本地数据、本地后端和第三方模型服务，避免把“本地优先”误解成“任何操作都不联网”。

GitHub Pages

Pages 静态页面本身不提供写作工坊账号系统或常驻后端。页面可以在浏览器 IndexedDB 保存本地项目；GitHub 作为托管平台仍可能按其政策记录常规访问日志。

浏览器与本地后端

浏览器数据

项目、章节、大纲、人物、笔记、记忆、AI 候选/恢复快照与界面状态保存在当前站点的浏览器存储中。清除站点数据会删除它们，请定期导出 v6 项目包；分享前检查其中是否含私稿或模型结果。

服务端数据

自部署模式会把后端项目、配置、能力和语料聚合档案写入你指定的工作目录。浏览器编辑不会静默覆盖后端项目；默认服务仅监听 127.0.0.1。

授权语料

真实网文指导库只接受你确认有权分析的 TXT、Markdown 或 DOCX。Pages 的本地分析在当前页面完成；自部署版发送到你自己的同源 Go 服务。两种模式都不持久化原文，只保存 SHA-256、文件元数据、分析指标、指导卡、AI 分析总结和提示词撤销记录；项目 v6 备份同样不包含语料原文。只有你主动点击“AI 深度分析”时，页面才会把不超过约 1.8 万字的分层抽样发送到你配置的模型服务，适用该服务商的数据条款。

模型与能力请求

当你主动执行 AI 任务时，Pages BYOK 会把明确选择的上下文直接发送到你配置的模型接口；自部署版则先发送到自己的 Go 后端。Skill 任务仍需要后端。第三方提供商如何保存与处理数据，取决于你与该提供商之间的条款。

密钥规则：Pages BYOK 的 API Key、Base URL、Provider 与 Model 保存在当前 origin 的 localStorage，不会写进仓库，但能被此页面脚本、浏览器扩展和可访问该浏览器数据的人读取。不要在公共设备使用，也不要把密钥写进前端代码、公开仓库、Issue 或截图；长期部署优先使用后端配置或环境变量。

第三方来源

登记 GitHub 仓库、Skill manifest 或远程链接不会自动执行其中代码。若未来启用代码型能力，应先核对来源、许可证、版本与权限，并使用隔离执行环境。

你可以做什么

  • 随时从浏览器或本地工作目录导出项目。
  • 删除浏览器站点数据或后端工作目录中的项目文件。
  • 使用环境变量保存密钥，并在服务商后台撤销密钥。
  • 运行前检查上下文包，不发送与本次任务无关的作品内容。

安全问题请按 SECURITY.md 报告；普通问题请使用 GitHub Issues。任何外部论坛账号都不作为本项目的隐私或安全联系渠道。
