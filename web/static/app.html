隐私条款与数据使用说明

📦 本地存储

Pages 正式在线版中，项目与正文保存在当前 github.io 域名的浏览器 IndexedDB，偏好保存在 localStorage。通过本地或自部署后端执行 AI 时，本次显式选择的上下文会发送到该后端及你配置的模型服务。

🍪 Cookie 使用

使用 localStorage 保存用户偏好与隐私提示确认状态，不使用第三方跟踪 Cookie。

🔑 API 调用

Pages 可由用户主动把 API Key 和自定义地址保存在当前浏览器并直连模型服务；不应在公共设备使用。自部署版推荐由同源后端保存 Key 并代发请求。默认 Pages 工作流仍不包含 Skill 等服务端执行层。

🛡️ 数据安全

可随时通过「清除数据」功能删除所有本地存储的数据。您的数据完全由您掌控。

🌐 第三方服务

静态资源可由本地或自部署后端提供，不加载外部 CDN 字体或脚本。

📬 联系方式

如有疑问，请通过 GitHub Issues 联系；安全问题请按仓库中的 SECURITY.md 报告。

📖 工作台内快速教程

需要逐按钮截图式路线时，打开 Pages 九步完整教程。

1. 建项目与资料归位

  1. 点击顶栏「＋」创建项目。
  2. 正文放章节，大纲、人物、笔记分别放对应资料区。
  3. 完成第一次重要编辑后，导出 v6 项目备份。

2. 配置 API

  1. 进入「设置 → API」。
  2. 填写模型、Base URL、Key 和协议；无 Key 服务选“无鉴权”。
  3. 先测试，成功后保存。Pages 直连需要目标接口允许浏览器 CORS。

3. 生成并确认候选

  1. 选中文本，再选择润色、续写、改写、对白或其他功能。
  2. 只加入本次需要的项目、大纲、人物、笔记与记忆，检查上下文预算。
  3. 生成结果先留在候选区，再决定替换、插入、追加、复制或记入记忆。

4. 真实网文指导库

  1. 进入「流程 → 真实网文指导库」。
  2. 导入有权分析的 TXT / MD / DOCX，确认权限后点「本地完整分析」。
  3. 查看综合总结、指标和带适用范围/证据/例外的指导卡。
  4. 可选「AI 深度分析」只发送约 1.8 万字以内的分层抽样；不点击就不发送原文。
  5. 保持档案启用，相关卡片会在润色、续写、对白、节奏等任务中动态调用。

5. Prompt Skill

在「流程 → 内置 Prompt Skill」查看每个功能的提示词。指导库可生成“修改旧指导块、追加、完整替换”三种候选；预览可编辑，确认后生效，并可按 Skill 精确回退。

6. 统一记忆

手工内容、写作/快捷/流程候选、语料总结、指导卡和提示词候选都能进入同一记忆表单。保存前检查标题、分类、来源、项目范围和内容；一次性命令放补充指令，不要存成长期记忆。

7. Pages 与自部署

  • Pages：项目、Prompt Skill、分析档案与 API 配置保存在当前浏览器。
  • 自部署：增加服务端 Key、后端 Skill、Go 语料 API、SSE 与后台记忆。
  • 浏览器与后端不会静默双向同步；需要迁移时显式导入/导出。

8. 手机端

用底部导航切换编辑、大纲、章节、人物、AI 和笔记。真实网文指导库位于 AI 面板的“流程”，候选与记忆操作与桌面端相同。

9. 备份与恢复

重要阶段导出 v6 项目包。它包含项目资料、记忆、候选快照、Prompt Skill 覆盖值和语料分析档案，不包含导入的真实网文原文。
