模型与 API 配置

自部署版由同源后端保存密钥；Pages 版会把配置保存在当前浏览器并直接请求模型接口。

Base URL 可填域名、兼容层地址或完整接口。Pages 直连无密钥服务时请选择“无鉴权”；是否可用仍取决于目标服务的 CORS。

能力来源

    
写作工坊是主体；GitHub 开源项目、skill、规则包和自定义文件只是可组合的能力来源。前端选择一个后端项目或多个 skill 后，把当前项目、章节、上下文和参数传给后端，后端输出再回传前端。

公开 Agent Skills / MCP 目录

    
默认不执行。 这里展示的是经过来源、许可证和权限初筛的上游入口。点击“登记元数据”只会创建一条停用能力记录，不会克隆仓库、安装包或运行第三方代码。

    
“WCP”并不是本项目采用的统一协议名；当前按可核验的 Agent Skills 与 Model Context Protocol（MCP）分别管理。生产接入前仍需固定版本、检查许可证、审查代码并设置最小权限。
